## 📋 What The Marketplace Is

The **STTAURX Marketplace** is a B2B commodities trading platform that:

| Feature | Description |
|---------|-------------|
| **Commodity Listings** | Gold, silver, copper, agricultural products |
| **Smart Letters of Credit** | Blockchain-based payment guarantees |
| **Supplier Portal** | Suppliers list products, manage orders |
| **Buyer Portal** | Buyers browse, purchase, track shipments |
| **STTAURX Integration** | Native support for gold-backed stablecoin |

### Port & Location
- **App URL:** `localhost:3003`
- **Code:** `/marketplace/`
- **Tech:** Next.js + TypeScript + Tailwind
